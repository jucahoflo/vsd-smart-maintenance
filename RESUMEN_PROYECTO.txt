3. BASE DE DATOS (SUPABASE)
================================================================================
Tabla vsd:
├── id (UUID) - Identificador único
├── codigo_vsd (TEXT) - Código del VSD
├── manufacturer (TEXT) - Marca
├── model (TEXT) - Modelo
├── serial_number (TEXT) - Número de serie
├── status (TEXT) - Estado (activo/mantenimiento/inactivo)
├── health_score (INTEGER) - Puntaje de salud (0-100)
├── site / plant (TEXT) - Ubicación
├── image_url_1 (TEXT) - URL imagen principal
├── image_url_2 (TEXT) - URL segunda imagen
└── image_url_3 (TEXT) - URL tercera imagen

Storage:
├── Bucket: vsd-images (público)
└── Estructura: vsd-id/timestamp-random.ext
